A tiny Python program (stdlib only) that writes one satirical sentence roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF, to `/output/entry.txt`. The roast sets up the lawmakers' authority — a 412-page law to govern artificial intelligence — and undercuts it with the file they cannot convert: they emailed their own staff to ask how to turn the law itself into a PDF. The punch lands on the last few words, and the specific detail beats the worn tech-illiteracy cliches.

Run it with `python3 main.py`. It creates `/output/` if needed and writes exactly one sentence (137 characters), well within the 320-character gate.
